My Portrait

A local-first AI memory system for macOS.

The goal is a proactive agent that knows me well enough to act for me. It starts with a memory built from what I see, hear and type.

Swift · macOS · GitHub · Download

Mean over 313 test frames. For each session, a larger model graded the three versions' write-ups against the original screenshots without knowing which was which. A 5 means the write-up matches the screen with nothing missing; a 1 means it is unusable. QAD recovers about 81% of the score that plain 4-bit quantization loses.
