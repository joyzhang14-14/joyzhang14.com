Sparky-toolbox

A personal agent harness built for the NVIDIA DGX Spark.

It is optimized specifically for local models. The agent lives in an offline sandbox, every tool call passes through a gateway with budgets, hooks and approvals, and untrusted content is read by isolated subagents, so the model stays precise and reliable across long, multi-step tasks.

Python · Linux · MIT · GitHub

It allocates the machine to the work. Each task, subagent and tool call is given the model, memory and context suited to it: models are loaded and swapped per job, tools run in containers within their declared limits, and context is assembled on demand instead of all at once.

It also improves itself. When the agent lacks an ability, it designs a new tool, task or subagent, builds and tests it in an isolated dev area, and ships it once approved. Its capabilities are not limited to what it was given.
