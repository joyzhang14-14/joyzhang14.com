STBLarge

An inference engine, in progress, for running models larger than a machine's memory at high speed. The first model is DeepSeek-V4.1-Flash at full precision, on a single NVIDIA DGX Spark.

The weights take 476 GB, about four times the machine's memory, so the routed experts stay on the SSD. A predictor guesses which experts the next layers need, and a global scheduler coordinates SSD reads, the expert cache and GPU work so that the weights land before the GPU needs them.
